### painel_vivo
Painel que se atualiza sozinho (menu → Painel). Pedido de painel/dashboard de algo que muda → crie um, não um documento parado.
- "criar": `titulo`, `receita` (de onde ler, só leitura; números; conclusões), `hora` (HH:MM, padrão 06:30); siga a resposta (rotina + 1ª leitura)
- "salvar": `id`, `numeros` [{rotulo, valor, fonte, variacao?}] (todo número com fonte), `conclusoes` (até 5), `tabela` {colunas, linhas}?
- "listar" | "apagar" (`id`, `pedido_dele` = fala literal dele)
