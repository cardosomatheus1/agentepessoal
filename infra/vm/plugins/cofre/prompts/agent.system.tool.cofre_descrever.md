### cofre_descrever
Registra para que serve uma senha do cofre (o site e a conta), para você saber qual usar sem perguntar. Nunca escreva o valor.
`nome`: o nome no cofre (ex.: GOOGLE_RAIZ). `para`: o site e a conta (ex.: "Google · matheus@raizconnect.com.br").
~~~json
{"tool_name": "cofre_descrever", "tool_args": {"nome": "GOOGLE_RAIZ", "para": "Google · matheus@raizconnect.com.br"}}
~~~
